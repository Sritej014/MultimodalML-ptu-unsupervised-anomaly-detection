# Master Thesis Repository

This private repository contains the code, documentation, and experiment tracking for my master thesis.

## Topic

Unsupervised anomaly detection for forming tool condition monitoring using Multi-modal Data (for example force time-series data and image data)

## Repository Structure

- `src/` — reusable Python scripts and modules
- `data_notebooks/` — exploratory notebooks
- `configs/` — experiment configuration files
- `reports/` — figures, notes, and thesis-related documentation
- `docs/` — additional documentation
- `results/` — generated outputs, ignored by Git if large

## Data Notice

Raw datasets are not stored in this repository because of size and confidentiality.  
Only code, configuration files, and selected lightweight result summaries are version-controlled.
